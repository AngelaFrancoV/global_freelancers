# global_freelancers
A descriptive analysis on Google Sheets

## Data
The dataset used contains 1,000 fictional freelancer profiles from around the world, including demographic, professional, and platform-related information. 
The dataset contained inconsistent and unclean values across several fields. 
### Data wrangling
- The gender and hourly rate columns contained inconsistent entries. I modified them to have only one format.
- Blanks were included in calculations, except for calculating correlations and for counting active freelancers.
- Only active freelancers were considered
